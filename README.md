# Productly - Landing Page

A responsive, clean, and fully functional landing page for **Productly**, built based on a Figma design.

## 🚀 Features

- **Semantic HTML5:** Built using semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) for accessibility and strong SEO.
- **Modern Responsive Layout:** Flexible 2-column grid and flexbox layouts that adapt seamlessly to desktop, tablet, and mobile screens.
- **Inline SVG Icons:** Clean vector rendering for key branding logos to avoid broken image file paths.
- **Interactive Component Elements:** Live HTML buttons, navigation links, and a mobile navigation menu toggle script.

## 🛠️ Built With

- **HTML5**
- **CSS3** (CSS Variables, Flexbox, CSS Grid)
- **Normalize.css**
- **Google Fonts** (Poppins)
- **FontAwesome** (Icons)
